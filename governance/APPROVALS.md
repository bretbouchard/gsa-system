# Approvals

Approvals are explicit checkpoints for actions whose consequences exceed the model's standing authority.

Examples include:

- destructive changes
- financial commitments
- manufacturing release
- publishing or externally visible communication
- elevated access
- privacy-sensitive operations
- actions with uncertain reversibility

## Approval request

A useful approval request should contain:

- proposed action
- reason
- affected resources
- expected outcome
- relevant evidence
- known risks
- rollback or recovery path
- cost or external consequence when applicable

Approvals are recorded as durable state so that later work can distinguish authorized execution from an unreviewed proposal.
